# Показания за сегодня

Список того, что вы внесли сегодня. Открывается кнопкой <span class="ui">Посмотреть внесённые</span> с главного экрана.

<div class="pair">
<img src="assets/screens/today.svg" alt="Экран «Показания за сегодня»: строка поиска по номеру прибора, счётчик найденных записей и карточки с номером, показанием, тарифом и типом прибора">
<div>

Главное, зачем сюда заходят, — убедиться, что показание дошло. Если после <span class="ui">Отправить</span> связь оборвалась и вы не увидели подтверждения, откройте этот список: запись либо есть, либо её надо внести заново.

Второе — найти прибор, который уже проходили, чтобы не снять его дважды.

Список приходит с сервера при каждом открытии экрана, поэтому он показывает записи всех устройств, а не только вашего телефона.

</div>
</div>

## Что в карточке записи

| Строка | Значение |
|---|---|
| <span class="ui">№ прибора:</span> | Заводской номер счётчика |
| <span class="ui">Показание:</span> | Отправленное значение |
| <span class="ui">Тариф:</span> | Тарифная зона: `T1`, `T2` или `T3` |
| <span class="ui">Тип:</span> | Модель прибора |
| <span class="ui">Разрядность:</span> | Количество цифр после запятой |
| <span class="ui">Фото</span> | Ссылка на снимок, приложенный к записи |

## Поиск

Строка вверху — <span class="ui">Поиск по № прибора учёта...</span>. Вводите номер целиком или его часть, список сужается по мере набора, а над ним показывается <span class="ui">Найдено:</span> с количеством совпадений.

Поиск работает только по номеру прибора. Искать по типу счётчика, тарифу или показанию нельзя.

## Состояния экрана

**<span class="ui">Загрузка данных...</span>** — список запрашивается с сервера.

**<span class="ui">За сегодня записей пока нет</span>** — сегодня ещё ничего не отправляли. Если вы точно отправляли, а список пуст, смотрите ниже.

**<span class="ui">Ничего не найдено по вашему запросу</span>** — записи есть, но ни одна не подходит под введённый номер. Проверьте, не опечатались ли, и попробуйте более короткий фрагмент номера.

**<span class="ui">Не удалось загрузить данные</span>** — сервер не ответил. Само по себе это не значит, что показания пропали: они на сервере, недоступен только список. Проверьте связь и откройте экран заново.

## Записи нет в списке

<div class="steps">
<div class="step">

### Обновите список

Вернитесь на главный экран и откройте <span class="ui">Посмотреть внесённые</span> снова — данные перезапросятся.

</div>
<div class="step">

### Проверьте, что было подтверждение

Запись появляется только после <span class="ui">Показание успешно сохранено!</span>. Если вы этого сообщения не видели, отправка не прошла.

</div>
<div class="step">

### Проверьте дату на телефоне

Список ограничен текущими сутками. Если на телефоне сбилась дата, записи «уезжают» в другой день.

</div>
<div class="step">

### Внесите заново

Если записи нет, а подтверждения не было — прибор не внесён. Снимите его ещё раз.

</div>
</div>

> [!WARNING]
> Не вносите показание повторно, пока не убедились, что его нет в списке. Дубликаты приходится разбирать вручную в учётной системе, и это дольше, чем один раз проверить.

## Чего здесь нет

**Вчерашних записей.** Экран показывает только текущий день. За прошлые дни обращайтесь в учётную систему.

**Правки и удаления.** Отправленное показание из приложения изменить нельзя. Ошиблись — сообщите мастеру участка, исправление делают на стороне учётной системы.

**Работы без связи.** Список всегда приходит с сервера, локальной копии в телефоне нет.
