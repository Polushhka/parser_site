# Первый запуск

## Камера

Нажмите <span class="ui">Внести показание</span> и разрешите доступ к камере. Если отказали, нажмите <span class="ui">Разрешить доступ</span>.

> [!ATTENTION]
> Если Android больше не показывает запрос: **Настройки → Приложения → Meter Parser → Разрешения → Камера**.

## Адрес сервера

<img src="assets/screens/settings.svg" alt="Экран настроек сервера: поле «Адрес сервера», кнопки «Сохранить» и «Сбросить к заводским», сообщение об успешном соединении">
<div>

Шестерёнка на главном экране → <span class="ui">Адрес сервера</span>. По умолчанию `https://meter.mosoblenergo.ru`; если ИТ-служба назвала другой, введите его и нажмите <span class="ui">Сохранить</span>.

Приложение сразу проверит соединение: <span class="ui">Адрес сохранён. Соединение с сервером установлено</span> означает, что всё в порядке.
