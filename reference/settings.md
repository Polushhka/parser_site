# Настройки сервера

Единственная настройка приложения — адрес сервера, на который уходят показания. Открывается шестерёнкой в правом верхнем углу главного экрана.

<div>

Экран открывается пояснением: <span class="ui">Укажите адрес бэкенда. По умолчанию — продакшен https://meter.mosoblenergo.ru</span>

Ниже — поле <span class="ui">Адрес сервера</span> с подсказкой <span class="ui">(например https://meter.mosoblenergo.ru)</span>, кнопка <span class="ui">Сохранить</span> и кнопка <span class="ui">Сбросить к заводским</span>.

</div>
</div>

> [!WARNING]
> Обходчику этот экран не нужен. Адрес по умолчанию уже верный, и менять его следует только по указанию ИТ-службы. Неверный адрес означает, что показания за смену уйдут в никуда.

## Формат адреса

Полный адрес со схемой:

```
https://meter.mosoblenergo.ru
```

Допустимо указать порт:

```
https://meter.mosoblenergo.ru:8443
```

И адрес по IP для тестового контура:

```
http://192.168.10.25:8000
```

Путь к API (`/api/upload` и остальные) дописывать не нужно — приложение добавляет его само.

## Проверка при сохранении

<span class="ui">Сохранить</span> не просто запоминает адрес — приложение сразу проверяет его и стучится на сервер. Возможные ответы:

| Сообщение | Что это значит | Что делать |
|---|---|---|
| <span class="ui">Адрес сохранён. Соединение с сервером установлено</span> | Адрес принят, сервер ответил | Ничего, можно работать |
| <span class="ui">Адрес сохранён, но не удалось подключиться к …</span> | Адрес записан, но сервер молчит | Проверить интернет и доступность сервера; адрес уже сохранён |
| <span class="ui">Адрес сохранён, но сервер вернул ошибку …</span> | По адресу что-то есть, но это не тот сервер или он неисправен | Сверить адрес с ИТ-службой |
| <span class="ui">Введите адрес сервера</span> | Поле пустое | Ввести адрес или нажать сброс |
| <span class="ui">Введите корректный адрес сервера</span> | Адрес не разобрался: опечатка, нет схемы, лишние символы | Проверить написание, начиная с `https://` |
| <span class="ui">Порт должен быть числом от 1 до 65535</span> | После двоеточия не число или число вне диапазона | Исправить порт или убрать его совсем |
| <span class="ui">Не удалось сохранить настройки</span> | Телефон не смог записать настройку в память | Проверить свободное место, перезапустить приложение |

Обратите внимание на разницу: первые три сообщения означают, что **адрес уже сохранён**, и повторно нажимать <span class="ui">Сохранить</span> не нужно. Остальные — что адрес отвергнут и поле нужно исправить.

При неудачной проверке приложение показывает и подсказку, куда смотреть:

```
Не удалось подключиться к серверу

Проверьте:
• Доступен ли сервер
• Правильный ли адрес
• Соединение с интернетом
```

## Сброс к заводским

<span class="ui">Сбросить к заводским</span> возвращает адрес по умолчанию. Приложение подтверждает: <span class="ui">Адрес сброшен к заводскому:</span> и показывает адрес.

Это первое, что стоит сделать, если приложение перестало отправлять показания после чьих-то правок в настройках.

## Где хранится адрес

Адрес хранится в памяти приложения на телефоне под ключом `@meter_parser_api_url` и переживает перезапуск. Удаление приложения его стирает — после переустановки адрес снова станет заводским.

> [!NOTE]
> Если в настройках стоит адрес по умолчанию, приложение считает, что настройка не менялась, и работает с продакшеном. Указанный вручную адрес, даже совпадающий с заводским, приложение помнит как пользовательский — на работу это не влияет.

## Переключение на тестовый контур

Порядок для ИТ-службы, когда телефон нужно временно увести на тестовый сервер:

<div class="steps">
<div class="step">

### Убедиться, что смена отработана

На тестовом контуре показания в учётную систему не попадают. Переключайте телефон, только когда обходчик не на маршруте.

</div>
<div class="step">

### Ввести адрес тестового сервера

Полностью, со схемой и портом: `http://10.0.0.15:8000`.

</div>
<div class="step">

### Дождаться подтверждения связи

Нужен ответ <span class="ui">Соединение с сервером установлено</span>. Любой другой — сервер недоступен с этого телефона, и в таком состоянии отдавать его обходчику нельзя.

</div>
<div class="step">

### Вернуть продакшен после проверки

<span class="ui">Сбросить к заводским</span> и снова дождаться подтверждения связи.

</div>
</div>
