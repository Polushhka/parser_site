# Учёт электросчётчиков

Руководство по мобильному приложению **Meter Parser** для обходчиков приборов учёта электроэнергии. Обходчик фотографирует счётчик, приложение распознаёт номер и показание, обходчик проверяет цифры и отправляет их на сервер.

Весь обход одного прибора занимает четыре действия: сфотографировать, проверить, отправить, идти дальше. Всё остальное в этом руководстве — про случаи, когда что-то пошло не так.

## Коротко о приложении

| | |
|---|---|
| Название | Meter Parser, на главном экране — «Учёт электросчётчиков» |
| Версия | 1.0.0 |
| Платформа | Android 7.0 и новее |
| Что нужно | Камера телефона и связь с сервером |
| Сервер по умолчанию | `https://meter.mosoblenergo.ru` |

## Четыре шага обхода

<div class="steps">
<div class="step">

### Сфотографировать счётчик

На главном экране — <span class="ui">Внести показание</span>. Наведите рамку на табло прибора и нажмите спуск. При плохом освещении включите подсветку.

</div>
<div class="step">

### Дождаться распознавания

Снимок уходит на сервер. Нейросеть возвращает номер прибора, показание, тарифность и тип счётчика.

</div>
<div class="step">

### Проверить цифры

Распознанные значения подставлены в поля. Сверьте их с табло и при необходимости исправьте вручную — это ваша ответственность, а не машины.

</div>
<div class="step">

### Отправить

<span class="ui">Отправить</span> — и показание в базе. Дальше <span class="ui">Добавить ещё</span> для следующего прибора или <span class="ui">На главную</span>.

</div>
</div>

> [!TIP]
> Распознавание — подсказка, а не источник истины. Последнее слово всегда за цифрами, которые вы видите на табло прибора. Если снимок вышел нечётким, быстрее переснять, чем набирать вручную.

## Кому какая часть руководства

**Обходчику.** Разделы «Приложение» и «Работа на обходе». Этого хватает, чтобы выйти на маршрут. Раздел «Сообщения и ошибки» держите в закладках — там разобрана каждая надпись, которую приложение может показать.

**Мастеру участка и диспетчеру.** Раздел «Справочник»: форматы полей, правила заполнения, что означает каждое сообщение и в каком случае обходчик не виноват.

**ИТ-службе и поддержке.** Раздел «Для ИТ-службы»: из чего собрано приложение, куда и что оно отправляет, как перенаправить его на тестовый контур.
